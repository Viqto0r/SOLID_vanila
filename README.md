# Принципы S.O.L.I.D.

## S — Single Responsibility Principle (Единственная ответственность)

Классы разделены по обязанностям (базовый Shape отвечает за общие свойства, AreaCalculator — за подсчёт площади, ShapeRenderer — за отображение и обновление статистики).

## O — Open/Closed Principle (Открыт/Закрыт)

Добавление новых типов фигур (например, Triangle) осуществляется без изменения существующих классов и логики рендера/калькулятора.

## L — Liskov Substitution Principle (Подстановка Лисков)

Все конкретные фигуры наследуют Shape и могут использоваться в одном массиве shapes.

## I — Interface Segregation (в примере проявляется частично)

Базовый класс задаёт минимально необходимые методы (calculateArea, render, getInfo) — каждая фигура реализует только их.

## D — Dependency Inversion (Инверсия зависимостей)

App оперирует абстракциями (массив shapes, AreaCalculator, ShapeRenderer) и не жёстко зависит от конкретных реализаций фигур.
